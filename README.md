# Memoria support workspace — frontend source

This project contains the React/Vite frontend retrieved from the Memoria preview.

## Run it

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL Vite prints.

## Scope

The source includes the Overview, Inbox, Customer, Analytics, and Feedback pages, plus styling and project configuration. The preview's backend API service is hosted separately and is not included here. Some screens therefore need that API service to load live data. No credentials or deployment secrets are included.
